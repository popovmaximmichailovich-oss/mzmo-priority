Критичные проверки

Рассчитанный реестр

На экране только управленчески значимые колонки. Полные 78 показателей остаются в базе, карточке и экспорте.

Полная таблица по всем объектам

Все показатели исходной Excel-модели. Пустые ячейки подсвечены красным. Выпадающие поля редактируются прямо в таблице, рейтинг пересчитывается автоматически.

Подсказка: красный фон — нет данных; серый фон — расчётные/служебные поля; изменение значения сразу пересчитывает F1–F6, рейтинг, зону и дашборды.

Карточка объекта

По умолчанию открыт краткий режим. Полные поля доступны через переключатель.

Мастер дозаполнения

Пошаговый сценарий: паспорт → техническое состояние → доступность → медицинская роль → надзорные риски → итог.

Массовое дозаполнение

Работает по текущему фильтру. Сначала отфильтруйте нужные объекты, затем применяйте значение.

Охват: не рассчитан.

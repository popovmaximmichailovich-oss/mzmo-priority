# Методика расчёта

Версия для GitHub Pages сохраняет широкий реестр Excel и переводит его в управляемую веб-модель.

## Расчётные блоки

F1 — технический риск: износ, состояние, год постройки, давность капитального ремонта.

F2 — территориальная безальтернативность: время доезда, наличие альтернатив, транспортная доступность.

F3 — программный/управленческий блок: адресный перечень, поручения, контур приоритизации.

F4 — надзорный и юридический риск: предписания, судебные/исполнительные документы, риск остановки.

F5 — системная роль / уникальность: ЦАОП, КТ/МРТ, рентгенологический контур, опорность, РСЦ/травмоцентр, маршрутизация, уникальность.

F6 — медицинская нагрузка: план/факт, профили, койки, экстренные обращения.

## Достоверность

Достоверность — доля заполненных обязательных полей из `data/config.json`.

`Нет данных` снижает достоверность. `Не применимо` не добавляет баллы и не должно заменять фактически отсутствующие сведения.

## v2.1. Массовое дозаполнение

Добавлен режим группового заполнения параметров по текущему фильтру таблицы. Логика применения:

- пользователь сначала сужает реестр поиском, зоной, типом или статусом данных;
- выбирает поле из списка редактируемых показателей;
- выбирает значение из справочника или вводит текст/число;
- применяет значение ко всем объектам текущего фильтра;
- выгружает JSON и вручную заменяет `data/objects.json` в GitHub.

Это позволяет быстро доводить большой реестр до рабочего качества без ручного открытия каждой карточки.

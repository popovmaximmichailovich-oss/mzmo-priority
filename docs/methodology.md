# Методика v2.3

Модель предназначена для предварительной управленческой приоритизации объектов здравоохранения для капитального ремонта, реконструкции, замещения мощности, дополнительного обследования или мониторинга.

## F-блоки

- F1 — технический риск.
- F2 — территориальная безальтернативность.
- F3 — программный / управленческий контур.
- F4 — надзорный и юридический риск.
- F5 — системная роль / уникальность.
- F6 — медицинская нагрузка.

## Принцип

Пользователь заполняет исходные признаки через выпадающие списки. Модель переводит признаки в баллы 0–3, рассчитывает рейтинг 0–100, зону приоритета и управленческую рекомендацию.

## Ограничение

Модель не заменяет обследование технического состояния, проектную документацию, экспертизу и обязательные требования нормативных документов.


## v2.4: полная таблица

Вкладка «Полная таблица» отображает все показатели исходной Excel-модели. Незаполненные ручные ячейки подсвечиваются красным. Расчётные поля выделяются серым и пересчитываются автоматически через F1–F6 и итоговый рейтинг.

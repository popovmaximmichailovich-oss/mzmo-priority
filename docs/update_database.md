# Обновление базы вручную

1. Откройте сайт.
2. Отфильтруйте нужные объекты.
3. При необходимости выполните массовое дозаполнение.
4. Нажмите «Экспорт JSON».
5. В репозитории замените файл `data/objects.json` новым экспортированным JSON.
6. Сделайте commit в ветку `main`.
7. GitHub Pages обновит сайт из ветки `main / root`.

Важно: локальное сохранение работает только в браузере пользователя. Чтобы изменения стали общей базой, нужно заменить `data/objects.json` в GitHub.

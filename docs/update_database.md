# Ручное обновление базы объектов

1. Откройте опубликованное приложение или локальную копию.
2. Отфильтруйте нужные объекты.
3. Используйте блок «Массовое дозаполнение» для группового заполнения параметров.
4. Проверьте дашборд и таблицу.
5. Нажмите «Экспорт JSON».
6. В репозитории GitHub замените файл `data/objects.json` выгруженным JSON-файлом.
7. Сделайте commit в ветку `main`.
8. GitHub Pages обновит опубликованную версию после выполнения публикации.

Важно: локальные изменения в браузере не попадают в GitHub автоматически. Источником опубликованной базы является файл `data/objects.json` в репозитории.

# Приоритизация объектов МЗ МО v2.3

Статическое веб-приложение для GitHub Pages и ручного обновления базы через `data/objects.json`.

## Что добавлено в v2.3

1. Главный экран **«Решение»** по выбранному объекту.
2. Режимы карточки: кратко, технические данные, медицинская нагрузка, надзорные риски, все поля.
3. Пошаговый **мастер дозаполнения**.
4. Расшифровка рейтинга F1–F6 по выбранному объекту.
5. Контроль логических противоречий и ошибок данных.
6. Экспорт: JSON, CSV, Excel-compatible `.xls`, печать/PDF карточки.
7. Сценарии приоритизации с разными весами F1–F6.
8. Экран методики внутри приложения.
9. Журнал изменений `docs/changelog.md`.

## Публикация на GitHub Pages бесплатно

1. Репозиторий должен быть Public.
2. `Settings → Pages`.
3. `Source: Deploy from a branch`.
4. `Branch: main`.
5. `Folder: / (root)`.

GitHub Actions workflow не используется.
